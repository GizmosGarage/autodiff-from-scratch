# Autodiff From Scratch

A small automatic differentiation engine built from scratch in Python.

## Why I'm Building This

I'm studying electrical engineering and learning calculus while developing a deeper understand of artificial intelligence and machine learning.

Rather than only using high-level AI frameworks, this project explores one of the fundamental mechanism that allows neural networks to learn:
automatic differentiation and backpropagation.

## Goals

- Understand computational graphs
- Understand derivatives and gradients
- Implement reverse-mode automatic differentation
- Understand backpropagation
- Build a tiny neural network using the engine
- Connect calculus concepts to machine learning

## Rules

I am using AI as a tutor and code reviewer rather than having AI generate the entire project for me.
